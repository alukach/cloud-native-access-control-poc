# Design working files

Artboards for the demo UI, authored as Design Components (`.dc.html`) and
published as a canvas: https://claude.ai/code/artifact/850883f3-a178-4602-8493-e16318fcc8e1

- `Current.dc.html` — the page as it ships, recreated for honest comparison
- `Main.dc.html` — the workbench direction under discussion
- `canvas.json` — layout, and the open questions as sticky notes

These are the source for the canvas; edit them and re-seed rather than editing
the published page. `access-control-demo-ui.html` is the built output and is
not committed.
