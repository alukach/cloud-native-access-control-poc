Access control on part of a file

Two real readers fetch two real files over HTTP range requests. Every range they ask for is resolved to the column chunks or image tiles it lands in, and checked against the CQL2 policy below before it is fetched. The question this page answers is not whether a policy can be written — it is whether a reader issues ranges a policy can act on.
